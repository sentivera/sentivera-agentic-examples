4.5 Loan Transactions

45.1 Transactions

Transactions are any time there is a monetary impact on the financial statements of the business, or any
time there is a change to the balance of a loan. Transactions are available for all loan programs except
HECM-A, HECM-lI, and SF Data Request.

If the transaction reduces the Unpaid Principal Balance to SO then the following will occur:

1. Payoff Request Timeline in the Servicing Module will automatically open and close with all steps
marked as complete with today’s timestamp.

2. Mortgage Release Timeline in the Mortgage Release Module will automatically open with the
first step marked as complete with today’s timestamp.

3. The Loan will close after the user refreshes the page.

4, The amount in the Payoff Letter will update to reflect the new Total Payoff Amount found in the
Payoff Tab, which is SO.

5. Arecord will automatically insert into the Transaction Tab.

If the transaction reduces the Unpaid Principal Balance to SO and there is already an open Mortgage
Release Timeline, then the following will occur:
1. Payoff Request Timeline in the Servicing Module will automatically open and close with all steps
marked as complete with today’s timestamp.
2. The Loan will close after the user refreshes the page.
3. The amount in the Payoff Letter will update to reflect the new Total Payoff Amount found in the
Payoff Tab, which is SO.
